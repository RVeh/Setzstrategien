| Funktion                                                           | Beschreibung                                                                                                                         | Beispielaufruf                                                                                                                          |
|:-------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------|
| **prepare_p_list**<br>`(p_values, exact=False)`                     | Listenkonvertierung in `Fraction`, falls `exact=True` und `Fraction` verfügbar.                                                       | `p_list = prepare_p_list([0.5,0.3,0.2], exact=True)`                                                                                    |
| **validate_p**<br>`(p_list, tol=0)`                                 | Prüft, ob die Summe von `p_list` in `±tol` um 1 liegt, wirft sonst `ValueError`.                                                     | `validate_p(p_list, tol=1e-8)`                                                                                                          |
| **generate_strategies_with_limits**<br>`(total_chips, m, minL, maxL)` | Erzeugt alle Verteilungen von `total_chips` auf `m` Felder mit komponentenweisen Grenzen.                                             | `for S in generate_strategies_with_limits(18,6,(1,3,2,1,1,0),(7,10,9,7,5,3)): …`                                                        |
| **P_A**<br>`(state_S, state_T)`                                     | Memoisierte Rekursion für \(P_A(S,T)\) im Ein-Würfel-Fall.                                                                             | `PA = P_A(tuple(V), tuple(W))`                                                                                                          |
| **compute_outcomes**<br>`(S,T)`                                     | Wrapper: liefert `(P_A,P_B,P_U)` mit \(P_B=P_A(T,S)\) und \(P_U=1-P_A-P_B\).                                                          | `PA,PB,PU = compute_outcomes(V,W)`                                                                                                       |
| **baue_P_gewinn**<br>`(p: Tuple[Fraction,…])`                       | Factory für eine Funktion `P(V,W)` im Ein-Würfel-Fall (ohne globale `p_list`).                                                        | `P = baue_P_gewinn(p); PA,PB,PU = P(V,W)`                                                                                                |
| **f**<br>`(S,T)`                                                    | (interne Helfer­funktion) berechnet eine Hilfsgröße in `baue_P_gewinn`.                                                               | Wird nicht direkt aufgerufen.                                                                                                           |
| **simulate_game**<br>`(p_vals,S,T,N=100000,seed=None)`              | Generischer Simulator für den Zwei-Würfel-Fall ohne Wald-CI (nicht typisiert nach A/B).                                                | `PA,PB,PU = simulate_game(p_list,V,W,N=50000,seed=42)`                                                                                  |
| **wald_ci**<br>`(p_hat)`                                            | Liefert `(p_hat,(low,high))` nach WALD-Formel für Bernoulli-Schätzer `p_hat`.                                                          | `p_hat, (l,h) = wald_ci(0.7)`                                                                                                            |
| **simulate_with_wald**<br>`(p_vals,S,T,N=100000,alpha=0.05,seed=None)` | Simuliert **1-Würfel**-Duell und gibt Schätzer + Wald-Konfidenzintervalle zurück.                                                      | `cis = simulate_with_wald(p_list,V,W,10000)`                                                                                            |
| **simuliere_duell_1_wuerfel**<br>`(S,T,p_vals,N=100000,alpha=0.05,seed=None)` | Alias für `simulate_with_wald`, deutsch benannt.                                                                                     | `cis1 = simuliere_duell_1_wuerfel(V,W,p_list,50000)`                                                                                     |
| **simuliere_duell_2_wuerfel**<br>`(S,T,pA_vals,pB_vals,N=100000,alpha=0.05,seed=None)` | Simulation für den **2-Würfel**-Fall mit getrennten Verteilungen für A und B inklusive Wald-CI.                                      | `cis2 = simuliere_duell_2_wuerfel(V,W,pA,pB,50000)`                                                                                       |
| **make_two_dice_recursion**<br>`(p1_list,p2_list)`                  | Factory für exakte Rekursion `P_A2(V,W)` im Zwei-Würfel-Fall über \(X/(1-p_{\rm stay})\).                                             | `P_A2 = make_two_dice_recursion(p_list,p_list); PA2 = P_A2(V,W)`                                                                         |
| **P_A2**<br>`(V,W)`                                                 | Memoisierte Funktion aus `make_two_dice_recursion`, berechnet exaktes \(P_A\) im Zwei-Würfel-Fall.                                     | `PA2 = P_A2(V,W)`                                                                                                                        |
| **P_fixiert**<br>`(S,p_vals,…,plot=True)`                           | Gestapeltes Balkendiagramm von \(P_A\) und \(P_B\) für feste Strategie S (ein Würfel). Speichert optional PDF und CSV.              | `P_fixiert(S,p_list,"x","y","Title",0.6,"PA","out.pdf","out.csv",False)`                                                                 |
| **P_fixiert_2dice**<br>`(S,pA_vals,pB_vals,…,plot=True)`            | Gestapeltes Balkendiagramm für feste Strategie S im Zwei-Würfel-Fall (mit getrennten pA/pB).                                            | `P_fixiert_2dice(S,pA,pB,"x","y","Title",0.6,"PA","out2.pdf","out2.csv",False)`                                                          |
| **find_better_strategies**<br>`(base,total_chips,minL,maxL,p_vals,exhaustive=True,seed=None)` | Sucht Strategien, die eine gegebene `base` schlagen (Vollsuche oder Hill-Climb).                                                  | `better = find_better_strategies((3,5,4,3,2,1),18,minL,maxL,p_list,True,42)`                                                             |
| **parse_limits**<br>`(arg)`                                         | Wandelt eine CSV-Limit-Angabe `"2,4,3,2,1,0"` in Tuple `(2,4,3,2,1,0)` um (CLI-Hilfsfunktion).                                           | `minL = parse_limits("1,3,2,1,1,0")`                                                                                                     |
| **main**<br>`()`                                                    | Kommandozeilen-Interface: CLI-Parameter, Suche, Plot-/CSV-Ausgabe bzw. Head(10) bei `--no-plot`.                                      | `python PropSetzstrategien.py --mode exhaustive --chips 18 --min 1,3,2,1,1,0 --max 7,10,9,7,5,3 --no-plot --csv out.csv`                    |
